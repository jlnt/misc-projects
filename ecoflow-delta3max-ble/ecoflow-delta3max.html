1 · Credentials
Getting started. The unit only talks to someone who knows two things: the User ID of the EcoFlow account it was set up with, and its own serial number.
  1. Find your User ID once — see how to find it below.
  2. Copy the serial number from the label on the unit (it starts with D3N1).
  3. Enter both, press Connect, and pick the unit from the list.

This page contains no credentials of its own. It remembers what you enter in this browser, or reads a file named ecoflow-credentials.js kept next to it. Keep these values private: anyone who has them and is within Bluetooth range can control the unit.

How do I find my User ID?

The User ID is a long number that identifies your EcoFlow account. The unit stored it when it was first set up with the EcoFlow app, and checks it on every Bluetooth connection. The app does not show it, but EcoFlow's login server returns it when you sign in. You only need to do this once; after that this page needs neither the app nor the internet.

Option A — in a browser, on a computer

  1. Open ecoflow.com in Chrome, Edge or Firefox.
  2. Open the developer console: press F12 (or ⌥⌘J on a Mac) and choose Console.
  3. Paste the snippet below and press Enter. If the browser refuses to paste, type allow pasting first, as it asks.
  4. Enter your EcoFlow email and password when prompted. The console prints your User ID.
(async () => {
  const email = prompt("EcoFlow account email:");
  const password = prompt("EcoFlow account password:");
  if (!email || !password) return;
  const res = await fetch("https://api.ecoflow.com/auth/login", {
    method: "POST",
    headers: { "Content-Type": "application/json", "Accept": "application/json" },
    body: JSON.stringify({
      scene: "IOT_APP", appVersion: "1.0.0", userType: "ECOFLOW",
      oauth: { bundleId: "com.ef.EcoFlow" },
      email, password: btoa(unescape(encodeURIComponent(password)))
    })
  });
  const out = await res.json();
  console.log(out.code === "0"
    ? "Your EcoFlow User ID: " + out.data.user.userId
    : "Login failed: " + out.message);
})();

Option B — from a terminal (if the browser blocks option A)

curl -s https://api.ecoflow.com/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"scene":"IOT_APP","appVersion":"1.0.0","userType":"ECOFLOW",
       "oauth":{"bundleId":"com.ef.EcoFlow"},
       "email":"YOUR_EMAIL",
       "password":"'"$(printf %s 'YOUR_PASSWORD' | base64)"'"}'

Replace YOUR_EMAIL and YOUR_PASSWORD. The number you want is data.user.userId in the reply.

Option C — Home Assistant

The ha-ef-ble integration's setup form can look the User ID up for you from the same login.

What these do. Both snippets send your email and password to EcoFlow's own login server and nowhere else; read them before running them. Nothing is sent to this page or to GitHub. If the login is rejected although the password is right, your account may live on a regional server: try api-e.ecoflow.com in place of api.ecoflow.com.

Advanced: use a precomputed auth secret instead of a User ID
